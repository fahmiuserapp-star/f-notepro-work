# F-Note Pro Max 🚀

An advanced hospitality and security delegation management tool tailored for hotels and high-security establishments. 

## ✨ Features
- **Multi-language Support:** Native 5 languages toggle (Arabic, French, English, German, Italian) with automated RTL/LTR directional adjustment.
- **Mobile-First Responsive UI:** Sleek, high-end theme inspired by premium hotel ethics (Olive & Gold).
- **Firebase Integration:** Secure Realtime Firestore syncing, Authentication, and Cloud Storage.
- **Export Capabilities:** One-click automated PDF and Image generation for instant sharing via WhatsApp or Printing.
- **Tunisian Plates Localization:** Dynamic inputs custom-built for Tunisian vehicle plates (TN) and diplomatic/administrative configurations.

## 🛠️ Technology Stack
- HTML5, CSS3 (Custom Properties & Dark Mode support)
- Vanilla JavaScript (ES6+)
- Firebase (Auth, Firestore, Storage)
- Html2pdf.js & Html2canvas
